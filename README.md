# Automation Platform

Student runtime environment for the Automation Platform.

The application runs with Docker and includes:

- Automation Platform backend
- MySQL 8.4
- Apache Kafka
- Production database
- Frontend Testing database
- API Testing database

The application source code is not required locally.

---

## Requirements

Install:

- Docker Desktop
- Git

Make sure Docker Desktop is running before starting the application.
